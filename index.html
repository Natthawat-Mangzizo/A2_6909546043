Title: Web Portfolio A2 (Responsive Upgrade)

Type: Course Assignment

Date: 11 ตุลาคม 2026

Role: Developer (วางโครงสร้างเว็บ เขียน CSS/Bootstrap และจัดการไฟล์ทั้งหมดด้วยตัวเอง)

Description: เป็นโปรเจกต์ยกทัพจัดรูปโฉมใหม่จากเว็บ A1 เดิม โดยเปลี่ยนมาใช้ Semantic HTML และดึงเอา Bootstrap 5 เข้ามาช่วยจัดเลย์เอาต์พวกการ์ดกับระบบ Grid เพื่อให้หน้าเว็บเปิดในมือถือแล้วไม่พัง จัดการโครงสร้างไฟล์และลองฝึกทำ Contact Form เพิ่มเติมครับ

Skills: HTML5 CSS3 Bootstrap 5 Responsive Design Git/GitHub

Reflection

  • What I did: เอาโค้ด A1 มาแก้ใหม่ ใช้แท็ก Semantic ให้ถูกต้องตามมาตรฐาน ลองเอา Bootstrap มาจัดเลย์เอาต์การ์ดรูปเกียรติบัตร และทำฟอร์มรับข้อความเพิ่ม
  • What I learned: เข้าใจวิธีใช้ Bootstrap Grid System (`row`, `col-md-4`) ว่ามันช่วยให้รูปปรับตามขนาดหน้าจอได้ง่ายขึ้นเยอะ และเข้าใจโครงสร้างการรับค่าพื้นฐานของ HTML Forms
  • Challenge: ช่วงแรกงงเรื่องการอ้างอิง Relative Path ของรูปกับโฟลเดอร์ CSS และการจัดประวัติ Commit บน GitHub ให้เป็นลำดับตาม Issue
  • Next step: อยากลองเอาผลงานอื่นๆ เช่น วิดีโอตัดต่อหรืออินโฟกราฟิกมาจัดวางเพิ่ม และลองศึกษา JavaScript เพิ่มเติมเพื่อทำให้เว็บมีลูกเล่น interactive มากขึ้นครับ
