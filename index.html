Portfolio Item 1

Title : Web Portfolio A2 (Responsive Upgrade)

Type : Course Assignment

Date : 11 ตุลาคม 2026

Role : Developer (วางโครงสร้างเว็บ เขียน CSS/Bootstrap และจัดการไฟล์ทั้งหมดเอง)

Description : เป็นโปรเจกต์ยกโฉมเว็บ A1 เดิมใหม่หมด โดยเปลี่ยนมาใช้ Semantic HTML และดึง Bootstrap 5 เข้ามาช่วยจัดเลย์เอาต์พวกการ์ดกับ Grid System ครับ เพื่อให้เปิดในมือถือแล้วหน้าเว็บไม่พัง จัดระเบียบไฟล์ใหม่ แล้วก็ลองเพิ่มฟอร์มติดต่อเข้ามาด้วย

Skills : HTML CSS Bootstrap 5 Responsive Design Git/GitHub

Reflection

  • What I did : รื้อโค้ด A1 มาปรับใหม่ ใช้แท็ก Semantic ให้ถูกตามมาตรฐาน เอา Bootstrap มาจัดเลย์เอาต์พวกการ์ดกับรูปภาพ แล้วก็ลองทำฟอร์มรับข้อความเพิ่มครับ
  • What I learned : เข้าใจการใช้ Bootstrap Grid System (row , col-md-4) มากขึ้นเยอะ ช่วยให้เว็บยืดหยุ่นตามหน้าจอได้ง่ายขึ้น แล้วก็เข้าใจพื้นฐานการทำ HTML Forms ครับ
  • Challenge : ช่วงแรกมีงงๆ เรื่อง Relative Path ของรูปกับ CSS แล้วก็เรื่องการจัดลำดับ Commit บน GitHub ให้ตรงตาม Issue ครับ
  • Next step : อยากลองเอาผลงานอื่นๆ มาจัดวางเพิ่ม แล้วก็ตั้งใจจะศึกษา JavaScript ต่อ เพื่อทำให้เว็บมีลูกเล่น interactive มากขึ้นครับ
